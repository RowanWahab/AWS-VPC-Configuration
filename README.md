# AWS VPC Configuration Assignment

## Project Overview
This project demonstrates the configuration of an Amazon Virtual Private Cloud (VPC) using AWS Management Console.

## Objectives
- Create and configure a custom VPC.
- Configure public and private subnets.
- Set up route tables and routing.
- Configure an Internet Gateway.
- Configure security groups and inbound/outbound rules.
- Verify the network configuration.

## Technologies Used
- Amazon Web Services (AWS)
- Amazon VPC
- AWS Management Console

## Implementation
The assignment demonstrates the step-by-step configuration of AWS networking resources, including VPC creation, subnet configuration, route tables, and security group settings.
